# Felix Desk

Brand di ClantoDesk per Data Felix (livello 1, Windows e macOS).

Questo repo contiene solo `brand.json` e `icons/`. La build la fa il workflow
«Partner build» di `clanto/clantodesk-client` con `partner: datafelix`, che firma
con i certificati Clanto e pubblica qui la release
(`datafelix-<versione>-x86_64.exe`, `.msi`, `.dmg`).

Le icone riproducono in vettoriale il monogramma del logo di datafelix.it
(grigio `#323431`, giallo `#FEDD0F`). Regole dei campi e delle icone:
`res/partner-template/README.md` in `clanto/clantodesk-client`.
